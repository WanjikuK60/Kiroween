# Product and style rules

- Project: a haunted portfolio site for the Kiroween 2026 Costume Contest.
- Stack: plain HTML, CSS and JavaScript. No build step, no runtime dependencies.
- Every spooky effect must serve usability: the lantern reveals content, the fog never hides text, and effects can be turned off.
- Accessibility is required: respect `prefers-reduced-motion`, keep keyboard focus visible, and keep text contrast readable inside the lantern.
- Palette: near-black background, warm parchment text, orange lantern accent. Headings use Creepster, body uses IM Fell English.
- Never add copyrighted audio or images. Generate sound with WebAudio.
- Do not add `.kiro` to `.gitignore`.
